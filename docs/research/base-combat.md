# Base combat research

Reference: Pokémon Showdown commit
`b79ce06d06b8f0dc8de8bb348bc9cab5d931553f`, Champions mod,
`gen9championsvgc2026regmc`.

## Source paths

- `data/mods/champions/scripts.ts` — `statModify` defines Champions stat
  points, nature rounding, and the Level Clause Mod formula; `calculatePP`
  defines Champions PP scaling.
- `sim/battle-actions.ts` — `hitStepAccuracy`, `getDamage`, and
  `modifyDamage` define accuracy stages, offensive/defensive stat selection,
  base damage, critical damage, random damage, STAB, and type ordering.
- `sim/battle.ts` — `modify` uses a 4096-based modifier with half-down
  rounding; `randomizer` selects an integer percentage from 85 through 100.
- `data/typechart.ts` — resolved attack/defense type relations. The exporter
  now records the resolved Champions chart instead of duplicating it by hand.
- `sim/dex-moves.ts` — `MoveData`, `MoveEventMethods`, `HitEffect`, and move
  flags define the behavior-bearing fields that PR 13.1 exports as capability
  requirements instead of reducing a move to power/category alone.
- `data/moves.ts` — resolved move definitions provide intrinsic secondaries,
  callbacks, multi-hit, drain/recoil, targeting, and control-flow metadata.

## Implemented slice

PR 13.1 supports any reachable move whose resolved definition requires exactly
the implemented single-target, one-hit standard-damage capabilities. The
checked manifest currently derives 37 such reachable moves. Runtime support is
not keyed by move identity: `MoveOperation` and `MoveCapabilities` are derived
from the broad resolved Dex's numeric fields, target, nested effects, behavior
callbacks, intrinsic flags, and special properties.

`Dragon Pulse` and `Dragon Claw` exercise the same executor as representative
Special and Physical moves. A move with omitted intrinsic behavior is rejected
before PP or move RNG is consumed. Focused regressions cover Flamethrower and
Shadow Ball (secondary), Facade (custom base-power callback), Surf (target
set), Bullet Seed (multi-hit), Giga Drain (drain), and Electro Shot
(charge/custom callback). Those moves are not degraded to plain damage.

Accuracy, critical hits, and the 85–100 damage roll consume `BattleRng`.
Move PP is deducted before accuracy. Damage applies critical, random, STAB,
then type modifiers in Showdown order. Immunities deal zero; other calculated
zeroes become one damage.

The focused fixture at `data/fixtures/differential/basic-damage.json` is
generated by `tools/showdown-reference/basic-damage.cjs`. Rust deserializes
that file directly and compares every expected stat and damage value. The
fixture currently covers 13 scenarios and all 16 damage percentages for 208
comparisons, including critical hits, positive and negative offensive and
defensive stages, Physical and Special representative moves, critical-stage
bypass rules, minimum-one rounding, and an immunity.

## Deferred behavior

Spread/random targeting, retargeting after a target leaves or faints, Struggle,
non-damage primary operations, move secondaries, move-specific callbacks,
multi-hit, drain/recoil, charge/control flow, and Mega Evolution remain
explicitly unsupported. Existing common-condition, field, and registered event
hooks continue to compose with supported damage. General ability/item coverage
preflight remains deferred to PR 13.5/13.6; PR 13.1 does not claim those source
families implemented.
